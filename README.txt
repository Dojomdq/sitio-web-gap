GAP - LANDING LISTA PARA VERCEL

Este ZIP contiene la landing estática con el archivo principal llamado index.html en la raíz del proyecto.

PUBLICACIÓN POR DRAG & DROP
1. Descomprimí este ZIP en tu PC.
2. En Vercel, abrí https://vercel.com/new.
3. Usá el flujo de despliegue de proyecto estático / Deploy without Git (si está disponible en tu cuenta) y seleccioná la CARPETA descomprimida GAP_Vercel_Drop, no el ZIP ni el archivo TXT.
4. Si Vercel pide configuración: Framework Preset = Other; Build Command = vacío; Output Directory = . (punto); Install Command = vacío.
5. Publicá y abrí la URL asignada.

IMPORTANTE
- index.html está en la raíz, para que Vercel lo sirva como página y no como descarga.
- No requiere Node, PHP, base de datos ni dependencias.
- Esta es la landing estática recuperada; no incluye panel de administración ni agenda dinámica.
- Si Vercel no permite desplegar un ZIP directamente en tu flujo, descomprimilo y subí la carpeta o importá esa misma carpeta desde GitHub/OpenCode.
